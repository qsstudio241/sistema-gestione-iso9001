## Matrice gap

| Modulo | Clausola / requisito | Fonte | Stato app oggi | Gap | Tipo | Priorità | Evidenza file |
|--------|----------------------|-------|----------------|-----|------|----------|---------------|
| | | | Implementato / Parziale / Assente / Backlog / N/A | | Normativo / Funzionale / Documentale | P0 / P1 / P2 | |

**Legenda Stato app oggi**

- **Implementato**: funzionalità presente e coerente con requisito
- **Parziale**: copertura incompleta o solo UI senza persistenza
- **Assente**: nessuna implementazione
- **Backlog roadmap**: pianificato in `PROJECT_ROADMAP.md`
- **N/A**: fuori perimetro o non applicabile

**Legenda Tipo gap**

- **Normativo**: requisito norma/Conforma non riflesso in checklist o flusso
- **Funzionale**: requisito coperto in linea di principio ma implementazione carente
- **Documentale**: testo normativo o template mancante in repo (non gap codice)
